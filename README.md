# GmodAddonHelper

This simple tool allows you to Publish GMAs to the workshop.

This will let you both create all new addons and update your existing ones in a simple GUI.



NOTE: This will not create GMAs. I would also recomend learning how to do publish and update addons manually, this tool is not meant to be a replacement for that knowledge, just something to speed up the tedious process


GMOD Workshop Addon Creation Wiki page.

https://wiki.facepunch.com/gmod/Workshop_Addon_Creation
